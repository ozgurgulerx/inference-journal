# 04 - CUDA Profiling

## Scope

- Profile real kernels and read Nsight output with confidence.
- Diagnose whether work is compute-bound, memory-bound, or launch-bound.

## Notes

Use `notes/` for profiling terminology, kernel anatomy, and counter interpretation.

## Experiments

Use `experiments/` for kernel runs, timeline captures, and performance counter investigations.

## Exit Criteria

- At least one non-trivial kernel is profiled and explained well.
- Nsight output can be translated into concrete optimization ideas.
