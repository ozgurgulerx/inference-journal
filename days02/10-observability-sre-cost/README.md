# 10 - Observability, SRE, and Cost

## Scope

- Measure the system as a production service, not only as a model runtime.
- Track latency percentiles, saturation, queueing, reliability, and unit economics.

## Notes

Use `notes/` for SLO definitions, dashboards, alert ideas, and service-level heuristics.

## Experiments

Use `experiments/` for load tests, dashboard snapshots, queue simulations, and cost studies.

## Exit Criteria

- There is a working SLO and a way to test it.
- p95 or p99 behavior is explained with service-level evidence.
