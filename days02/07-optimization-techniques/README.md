# 07 - Optimization Techniques

## Scope

- Study batching, speculative decoding, prefix reuse, quantization, and other performance levers.
- Separate real wins from marketing claims.

## Notes

Use `notes/` for tradeoff summaries, technique comparisons, and rules of thumb.

## Experiments

Use `experiments/` for optimization bakeoffs and ablation studies.

## Exit Criteria

- Each optimization has a measured benefit and a documented cost.
- At least one technique is rejected with evidence, not intuition.
